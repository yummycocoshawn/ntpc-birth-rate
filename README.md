# 新北市出生率 19 年(2007–2025)

新北市(2010 年前為臺北縣)歷年粗出生率、出生數、男女嬰、29 個行政區與生母年齡的 ETL + 互動式網頁(BI)。

- 網頁:<https://yummycocoshawn.github.io/ntpc-birth-rate/>
- 統計基準:**按發生日期**(依出生當年),全專案不混用「按登記日期」。
- 涵蓋:民國 96–114 年(西元 2007–2025);尚未滿一整年的年份不收。

## 目錄

```

etl/    etl_births.py 轉換、validate.py 驗證、build_data.py 產生網頁資料、download_ris_api.sh 下載 API

docs/   網頁(index.html、data.js),也是 GitHub Pages 的發佈來源;另有來源明細與 SHA-256 清單
```

被排除(`.gitignore`)的是 `raw/ris_api/ODRP028`、`ODRP055`、`ODRP056`、`ODRP059`(共約 840 MB)。它們是出生按生母年齡、國籍、教育程度的 API 備份,目前的 ETL 沒有使用;需要時用 `etl/download_ris_api.sh` 重新下載。

## 重現指令

需要 [uv](https://docs.astral.sh/uv/);套件由各腳本開頭的 inline script metadata 自動安裝,不必另建環境。

```bash
uv run etl/etl_births.py     # raw/ -> data/*.csv
uv run etl/validate.py       # 對照 raw/ 驗證 data/,全部通過才 exit 0
uv run etl/build_data.py     # data/*.csv -> docs/data.js
# 然後用瀏覽器開 docs/index.html(data.js 要在同一個資料夾)
```

- 重新下載 API 檔:`etl/download_ris_api.sh ODRP013 11412`(端點與民國年月)。
- 「快速下載」的 Excel 需要在戶政司網頁上逐一點選下載,沒有穩定的直接網址,所以原始檔直接放在 `raw/ris_fastdownload/` 與 `raw/ris_town_pop/`。
- Windows 若終端機亂碼,先設定 `PYTHONUTF8=1`。

## 欄位說明

三份 CSV 皆為長表,缺值留空(不是 0),原因寫在 `status`。民國年已轉西元年。

### `data/births_city.csv`(縣市,2007–2025)

| 欄位 | 說明 |
|---|---|
| year | 西元年 |
| area | 地區;`全國` 或現今名稱。臺北縣對應為新北市 |
| name_at_time | 來源表當時印的名稱(如 臺北縣、桃園縣、臺中縣、總計) |
| area_type | `全國`/`直轄市`/`縣市`,依 name_at_time 當時的類型 |
| sex | `總計`/`男`/`女` |
| births | 出生數(人),按發生日期 |
| mid_year_population | 年中人口(人),估算,見下 |
| population_source | `年底人口平均(估)` 或空 |
| crude_birth_rate | 粗出生率(‰) |
| rate_source | `原始`(來源表公布值)或 `計算`(出生數 ÷ 年中人口 × 1000) |
| status | `正常` 或缺值原因 |

### `data/births_district.csv`(新北市 29 區,2007–2025)

欄位同上,以 `district`(現今行政區名)取代 area/sex,`name_at_time` 為當時名稱(如 板橋市→板橋區)。各區沒有官方按發生的粗出生率,一律為 `計算`,且只有 2009 年起有值(需要前一年底人口,區級人口最早到 2008 年底)。

### `data/births_mother_age.csv`(新北市,2007–2025)

| 欄位 | 說明 |
|---|---|
| year | 西元年 |
| age_group | 20歲以下、20-24歲、25-29歲、30-34歲、35-39歲、40-44歲、45歲以上 |
| births | 該年齡組出生數 |
| share | 占當年各組合計的比例 |
| status | `正常` 或缺值/不一致原因 |

## ETL 與驗證做了什麼

`etl/etl_births.py`
- 民國年 +1911;只取按發生日期的欄位(登記與發生不混用,理由寫在程式註解)。
- 臺北縣在 2010 年以前對應為新北市,`name_at_time` 保留原名;其他縣市的改名與合併(桃園縣→桃園市、臺中縣等)不對應,避免重複計算。
- 有官方粗出生率就用原值(`rate_source=原始`),沒有才自行計算(`計算`)。
- 年中人口 = 前一年底與當年底人口的平均;2010 年直轄市合併時,前一年底人口為原市加原縣。這是估算,不是官方值。
- 「－」「…」與空白視為缺值,留空並在 status 說明;滿一整年以前的年份整列移除。

`etl/validate.py`(自行重新讀 raw/,不 import ETL,避免共用同一個錯)
- 有數值的筆數與總和與原始檔一致;沒有重複鍵;年份連續。
- 男嬰加女嬰等於總計;29 區出生數加總等於新北市全市(逐年列出差異)。
- 自算粗出生率與官方值差距不超過 0.05‰;各生母年齡組加總等於當年出生數;粗出生率落在 0–50‰。
- 全部通過 exit 0,任何一項失敗會印出是哪幾筆。目前 20 項全部通過;驗證時抓到並修正過一個驗證程式自己的錯(2014 年前的「桃園市」是縣轄市,不是縣市)。

## 使用注意事項

- **粗出生率** = 全年出生數 ÷ 年中人口 × 1000,單位‰。它受人口年齡結構影響,**不等於生育意願**;要看生育行為請用年齡別生育率或總生育率(本專案未提供)。
- **2010 年前是臺北縣。** 來源表把 2010 年整年以「新北市」列出,所以 2007–2009 是臺北縣,2010 年是改制當年。臺中、臺南、高雄也在 2010 年合併升格,範圍變大,與 2009 年以前不可直接比較。
- **小區人口少,比率波動大。** 例如烏來區年中人口約 6 千人,多少幾個新生兒就差好幾‰,請搭配出生數看。
- **2007–2008 年沒有各區粗出生率**,2007–2019 年的縣市原始粗出生率只有 1 位小數。
- **虎年龍年**等習俗會造成個別年份起伏,單看一年容易誤判。
- 本專案只描述差異,**不代表因果**。
- 1998–2006 年只有按登記資料,依「不混用」原則未納入;逐年按登記檔仍保留在 `raw/ris_fastdownload/` 供對照。
